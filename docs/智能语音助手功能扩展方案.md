# Vela 智能语音助手功能扩展方案

## 一、功能概述

在原有 Vela 智能桌面管家基础上，增加**语音小智**功能，实现：

1. **双模式语音交互**
   - **离线模式**：使用现有 KWS 固定指令识别（温度、湿度、光照、空气质量查询）
   - **在线模式**：接入小米 MiMo 大模型，实现智能对话

2. **唤醒词支持**
   - 唤醒词：**"你好，openvela"**
   - 基于现有 KWS 模型的 `VOICE_COMMAND_WAKE` 类别实现

3. **Web 配置界面**
   - 在局域网 Web 面板中配置 MiMo API Key
   - 切换离线/在线语音模式
   - 配置 TTS 音色选择

4. **完全向后兼容**
   - 不影响原有离线固定指令功能
   - 配置默认为离线模式
   - 所有新功能可选启用

### 2.2 数据流

#### 离线模式流程
```
用户语音 → DMIC录音 → KWS模型识别 → 固定指令匹配 → 传感器查询 → TTS播报
```

#### 在线模式流程（唤醒后）
```
"你好openvela" → KWS唤醒词检测 ✓ → 继续录音
↓
用户问题 → MiMo ASR → 文字
↓
文字 → MiMo LLM → 智能回答
↓
回答 → MiMo TTS → 语音播报
```

## 三、核心代码文件

### 3.1 新增文件

1. **mimo_integration.h / .c**
   - MiMo API 封装层
   - 提供 ASR、LLM、TTS 接口
   - 自动处理 `tp-` token plan 和普通 API key
   - 路径：`app/routine_manager/mimo_integration.{h,c}`

2. **voice_recognizer_online.h / .c**
   - 扩展的语音识别器
   - 支持唤醒词检测
   - 统一处理离线/在线模式
   - 路径：`app/routine_manager/voice_recognizer_online.{h,c}`

3. **voice_config_api.h / .c**
   - Web API 接口实现
   - 处理语音配置的读取和更新
   - 路径：`app/lan_panel/voice_config_api.{h,c}`

### 3.2 修改文件

1. **routine_model.h**
   - 新增 `enum routine_voice_mode_e`（离线/在线模式）
   - 扩展 `struct routine_settings_s` 增加 MiMo 配置字段

2. **routine_config.c**
   - 扩展配置加载/保存逻辑
   - 支持 `voice_mode`、`mimo_enabled`、`mimo_api_key` 等字段

3. **audio_service.c / .h**
   - 集成 `voice_recognizer_online`
   - 根据配置选择离线/在线模式
   - 处理唤醒词后的持续对话

4. **lan_panel_main.c**
   - 添加 `/api/v1/voice/config` 路由
   - 集成 `voice_config_api`

## 五、API 接口

### 5.1 GET /api/v1/voice/config

**功能**：获取当前语音配置

**请求**：
```http
GET /api/v1/voice/config HTTP/1.1
Host: 192.168.1.100:8080
Authorization: Bearer 1234
```

**响应**：
```json
{
  "voice_mode": "offline",
  "mimo_enabled": false,
  "has_api_key": false,
  "mimo_model": "mimo-v2.5",
  "mimo_tts_voice": "冰糖"
}
```

**注意**：`mimo_api_key` 不会返回实际值，只返回 `has_api_key` 布尔值（安全考虑）

### 5.2 POST /api/v1/voice/config

**功能**：更新语音配置

**请求**：
```http
POST /api/v1/voice/config HTTP/1.1
Host: 192.168.1.100:8080
Authorization: Bearer 1234
Content-Type: application/json

{
  "voice_mode": "online",
  "mimo_enabled": true,
  "mimo_api_key": "sk-xxxxxxxxxxxxxx",
  "mimo_model": "mimo-v2.5",
  "mimo_tts_voice": "冰糖"
}
```

**响应**：
```json
{
  "status": "success",
  "message": "Voice config updated"
}
```

## 六、使用指南

### 6.1 离线模式（默认）

1. 开机后默认为离线模式
2. 点击屏幕"开始语音"
3. 说出固定指令：
   - "现在温度多少"
   - "现在湿度多少"
   - "现在光照多少"
   - "现在空气质量怎么样"
4. 系统识别后播报结果

### 6.2 在线模式配置

#### 步骤 1：获取 MiMo API Key
1. 访问小米 MiMo 官网注册账号
2. 获取 API Key（格式：`sk-xxxxx` 或 `tp-xxxxx`）

#### 步骤 2：Web 配置
1. 设备连接 Wi-Fi
2. 浏览器打开 `http://<设备IP>:8080/`
3. 输入 4 位访问令牌
4. 进入"语音配置"页面
5. 填写配置：
   - 选择"在线模式"
   - 输入 MiMo API Key
   - 选择模型（推荐 `mimo-v2.5`）
   - 选择音色（默认"冰糖"）
6. 点击"保存"

#### 步骤 3：使用在线语音助手
1. 点击屏幕"开始语音"
2. 说"你好，openvela"（唤醒词）
3. 听到唤醒确认后，继续说出问题：
   - "今天天气怎么样？"
   - "帮我设置一个提醒"
   - "现在温度多少？"（也支持固定指令）
4. 系统通过 MiMo 理解问题并智能回答

### 6.3 切换模式

随时通过 Web 界面切换离线/在线模式：
- **离线模式**：不需要网络，仅支持4个固定指令
- **在线模式**：需要 Wi-Fi + API Key，支持智能对话

## 七、技术细节

### 7.1 唤醒词实现

基于现有 KWS 模型的 `VOICE_COMMAND_WAKE` 类别：
- 模型文件：已在训练集中包含"你好 Vela"样本
- 阈值设置：`score > 180`
- 检测函数：`voice_recognizer_detect_wake_word()`

**扩展方法**：
如需更换唤醒词，需要：
1. 采集新唤醒词语料（使用 `kws_capture` 模式）
2. 更新训练集并重新训练模型
3. 替换 TFLite Micro 模型文件

### 7.2 MiMo API 调用

#### ASR (语音转文字)
```c
struct mimo_asr_result_s asr_result;
mimo_asr(mimo_service, "/data/audio/record.pcm", &asr_result);
// asr_result.text 包含识别文本
```

#### LLM (对话)
```c
struct mimo_llm_response_s llm_response;
mimo_llm_chat(mimo_service, "现在几点了？", &llm_response);
// llm_response.text 包含回答
```

#### TTS (文字转语音)
```c
struct mimo_tts_result_s tts_result;
mimo_tts(mimo_service, "当前时间是下午3点", &tts_result);
// tts_result.audio_path 包含生成的 PCM 文件路径
```

### 7.3 安全考虑

1. **API Key 存储**
   - 存储在 `/data/routine/config.json`（权限 0600）
   - Web API 不返回实际 Key 值
   - 仅返回是否已配置的布尔值

2. **输入验证**
   - 所有 API 请求经过 JSON 解析验证
   - 字符串长度限制
   - 特殊字符转义

3. **原子写入**
   - 配置更新使用临时文件 + rename
   - 避免写入中断导致配置损坏

## 十、故障排查

### 10.1 MiMo API 调用失败

**现象**：在线模式无响应

**排查**：
1. 检查网络连接：`ping api.xiaomimimo.com`
2. 检查 API Key 配置：`cat /data/routine/config.json | grep mimo_api_key`
3. 查看日志：`dmesg | grep -i mimo`

### 10.2 唤醒词识别率低

**解决方案**：
1. 采集更多说话人样本
2. 调整唤醒阈值（降低 score 要求）
3. 重新训练 KWS 模型

### 10.3 配置保存失败

**排查**：
1. 检查 `/data` 分区空间：`df -h`
2. 检查文件权限：`ls -l /data/routine/`
3. 查看错误日志
