## 💡 关键技术点

### 1. 唤醒词实现
- 基于现有 KWS 模型的 `VOICE_COMMAND_WAKE` 类别
- 阈值：`score > 180`
- 需要训练数据中包含"你好，openvela"样本

### 2. MiMo API 调用
- 使用 `curl` 命令行工具调用 HTTP API
- 支持 `tp-` token plan 和普通 API Key
- 自动选择正确的 API endpoint

### 3. 安全设计
- API Key 存储在 `/data/routine/config.json`（0600）
- Web API 不返回实际 Key 值
- 配置文件原子写入（临时文件 + rename）

### 4. 向后兼容
- 默认离线模式，不影响现有功能
- 配置文件兼容旧版本
- 新字段有合理默认值

## 🐛 已知限制

1. **唤醒词识别率**
   - 依赖于训练数据质量
   - 可能需要针对不同说话人采集样本

2. **网络依赖**
   - 在线模式需要稳定的网络连接
   - API 调用有延迟（通常 1-3 秒）

3. **连续对话**
   - 当前版本每次需要重新唤醒
   - 未实现多轮对话上下文

4. **资源消耗**
   - MiMo API 调用消耗流量和 API 配额
   - 建议离线模式为主，在线模式为辅
