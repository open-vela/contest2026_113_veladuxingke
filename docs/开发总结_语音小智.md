## 七、性能指标

### 延迟分析

| 阶段 | 时间 | 说明 |
|------|------|------|
| VAD 检测 | ~60-100ms | 连续 3 帧判定 |
| 录音 | 1-7秒 | 取决于说话长度 |
| 语音结束检测 | ~500ms | 静音判定 |
| MIMO ASR | ~1-2秒 | 网络 + 云端识别 |
| MIMO LLM | ~1-3秒 | 取决于回复长度 |
| MIMO TTS | ~1-2秒 | 网络 + 音频生成 |
| **总延迟** | **~5-15秒** | 从说话到听到回复 |

### 成本估算 (MIMO Token Plan)

| 操作 | Token 消耗 | 说明 |
|------|-----------|------|
| ASR (3秒音频) | ~10 tokens | 语音转文字 |
| LLM (简单问答) | ~50-100 tokens | 生成回复 |
| TTS (20字回复) | ~10 tokens | 文字转语音 |
| **每次交互** | **~70-120 tokens** | |

### 资源占用

| 资源 | 占用 | 说明 |
|------|------|------|
| RAM | ~50KB | 音频缓冲 + 服务数据 |
| Flash | ~30KB | 代码增量 |
| CPU | ~10% | 后台监听线程 |
| 网络 | 间歇性 | 仅识别时使用 |

## 八、已知限制

1. **需要网络连接** - MIMO API 依赖联网
2. **延迟较高** - 云端处理，总延迟 5-15 秒
3. **成本** - 每次交互消耗 API tokens
4. **唤醒词固定** - 当前只支持"你好Vela"
5. **无离线能力** - 在线模式下无法离线工作
