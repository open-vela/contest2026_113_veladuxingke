【下一步行动】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 获取 MIMO API Key
   → https://mimo.mi.com

2. PC 端测试 API
   → cd tools
   → ./test_mimo_api.sh tp-your-key

3. 根据测试结果调整代码
   → 参考: docs/MIMO_API验证指南.md
   → 参考: docs/MIMO_API注意事项.md

4. 确认关键问题
   → □ Chat 响应格式 (嵌套 vs 平铺)
   → □ ASR 音频格式 (PCM vs WAV)
   → □ TTS 输出正常
   → □ 模型版本号正确

5. 编译和烧录
   → ./tools/build_voice_wakeup.sh
   → 烧录镜像到板子

6. 真机测试
   → 配置 API Key
   → 点击 "离线" → "在线"
   → 说 "你好Vela，现在温度多少？"
