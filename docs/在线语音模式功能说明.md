# 在线语音模式功能说明

## 概述

在线语音模式是 Vela 智能桌面管家的重要升级，通过集成 MiMo 云端语音服务，从固定指令识别升级为支持自然语言对话的智能助手。

## 核心功能

### 1. 通用中文 ASR（语音识别）

- **技术**：MiMo mimo-v2.5-asr 模型
- **特点**：支持自然语言，不限于固定指令
- **实现**：PCM 音频加 44 字节 WAV 头，base64 编码后通过 HTTPS 发送到 MiMo API
- **效果**：可以识别任意中文语音，包括"现在温度是多少"、"帮我看看湿度"等自然表达

### 2. 智能对话 LLM

- **技术**：MiMo mimo-v2.6-pro 大语言模型
- **特点**：结合传感器上下文理解用户意图
- **传感器上下文**：自动注入温度、湿度、光照、CO₂、TVOC 实时数据到 system prompt
- **效果**：AI 能分析环境数据并给出智能建议，如"24℃正适合跑步"

### 3. 自然语音 TTS（语音合成）

- **技术**：MiMo mimo-v2.5-tts 模型
- **音质**：24kHz 高质量中文语音，自动重采样到 16kHz 播放
- **音色**：支持 8 种官方音色
  - 中文女声：冰糖、茉莉、苏达、白桦
  - 英文女声：Mia、Chloe
  - 英文男声：Milo、Dean
- **实现**：base64 解码 → 检测 RIFF 跳过 44 字节头 → 24kHz 线性插值重采样到 16kHz → 保存到 `/data/mimo_tmp/tts_output.pcm` → NxPlayer 播放

### 4. AI 智能控制

#### 温度阈值调节

支持通过自然语言调节温度阈值：

```
"把最低温调到25度"         → 设置低温阈值 25℃（高温阈值保持）
"把最高温调到30度"         → 设置高温阈值 30℃（低温阈值保持）
"温度阈值20到30度"         → 设置低温 20℃，高温 30℃
"最低温度改成18度"         → 设置低温阈值 18℃
```

**意图识别关键词**：
- 低温：`最低温`、`低温`、`调到`、`设为`、`改成`
- 高温：`最高温`、`高温`
- 双阈值：同时包含两个数字

**中文数字支持**：
- 支持："二十五度"、"三十度"
- 校验：0–50℃ 范围，低温 < 高温

#### 日程提醒添加（待验证）

支持通过自然语言添加日程提醒：

```
"七点半提醒我跑步"         → 07:30 提醒：跑步
"早上八点提醒我吃药"       → 08:00 提醒：吃药
"下午三点提醒我开会"       → 15:00 提醒：开会
"十点半提醒我去跑步"       → 10:30 提醒：去跑步
```

**时间识别**：
- 方法1：`X点` 格式（中文数字/阿拉伯数字）
- 方法2：时间段 + 数字（早上/上午/中午/下午/晚上）
- 方法3：`HH:MM` 格式
- 支持"半"表示 30 分钟

**槽位策略**：
- 优先查找空槽位（`id == 0`）
- 若无空槽位，自动替换时间最接近的现有日程

### 5. 双向实时同步

所有配置在 Web 端和设备端自动同步：

- **在线/离线模式**：Web 端或设备屏幕切换后，通过 `generation` 机制实时同步
- **温度阈值**：Web 端或语音修改后，立即更新到设备和 Web
- **日程提醒**：Web 端或语音添加后，立即显示在设备屏幕和 Web 端
- **MiMo 配置**：API Key、LLM 模型、TTS 音色实时保存到 `/data/routine/config.json`

## 技术架构

### 文件结构

```
app/routine_manager/
├── mimo_integration.c/h      # MiMo API 集成层
│   ├── mimo_asr()            # ASR 语音识别
│   ├── mimo_llm_chat()       # LLM 对话（带传感器上下文）
│   ├── mimo_tts()            # TTS 语音合成
│   ├── mimo_set_temperature_threshold()  # 温度阈值控制
│   ├── mimo_add_schedule_reminder()      # 日程提醒管理
│   └── mimo_detect_and_execute_intent()  # 意图识别
├── voice_recognizer_online.c/h  # 在线语音识别器
│   └── voice_recognizer_online_process()  # ASR → LLM → 意图 → TTS 完整链路
├── routine_ui.c              # LVGL UI（模式切换按钮）
└── routine_config.c          # 配置持久化

app/lan_panel/
├── lan_panel_main.c          # Web API 后端
│   ├── GET  /api/voice/config   # 读取语音配置
│   └── POST /api/voice/config   # 保存语音配置
└── voice_config.html         # 语音配置页面
```

## 已知限制

### 1. VAD 自动静音检测失败

**问题**：录音文件写入不均匀导致 `diff` 常为 0，`silence_duration` 最多 40ms，从不触发。

**临时方案**：固定 10 秒录音（`max_record_ms = 10000`）

**用户诉求**：说完自动结束，不用固定时长（待优化）

### 2. Function Calling 未完整实现

**现状**：`mimo_get_tools_json()`、`mimo_execute_function()` 是未使用的框架代码。

**当前方案**：简化版意图识别（关键词匹配）

**改进方向**：接入真正的 Function Calling 多轮循环

### 3. 提醒内容提取启发式

**问题**：通过关键词和位置提取，可能不够准确。

**示例**：
- "七点半提醒我跑步" → 提取"跑步"✓
- "七点半提醒我去跑步" → 提取"去跑步"✓
- "提醒我七点半跑步" → 可能提取失败

### 4. Web 端修改配置的模式切换问题

**问题**：在 Web 端修改阈值或日程时，有时会自动切换到离线模式（原因待定位）

**临时方案**：修改后手动切换回在线模式

## API 参考

### MiMo ASR API

```http
POST https://token-plan-cn.xiaomimimo.com/v1/chat/completions
Content-Type: application/json

{
  "model": "mimo-v2.5-asr",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "input_audio",
          "input_audio": {
            "data": "data:audio/wav;base64,UklGR...",
            "format": "wav"
          }
        }
      ]
    }
  ],
  "asr_options": {
    "language": "zh"
  }
}
```

### MiMo LLM API

```http
POST https://token-plan-cn.xiaomimimo.com/v1/chat/completions

{

  "messages": [

}
```
