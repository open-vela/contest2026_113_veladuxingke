## 🔧 技术实现亮点

### 1. **智能识别流程**
```
录音 → 在线模式？
├─ 是 → 唤醒词检测
│   ├─ 检测到 → 播报确认，等待问题
│   ├─ 固定指令 → 回退离线逻辑
│   └─ 其他 → MiMo ASR → LLM → TTS → 播报
└─ 否 → KWS 固定指令 → 传感器查询 → 播报
```

### 2. **安全设计**
- API Key 存储在 `/data/routine/config.json` (权限 0600)
- Web API 不返回实际 Key 值（仅返回 `has_api_key` 布尔值）
- 配置文件原子写入（临时文件 + rename）
- 输入验证和转义

### 3. **模块化架构**
- MiMo 集成层完全独立
- 在线识别器包装统一接口
- Web API 独立模块
- 最小侵入式修改

### 4. **向后兼容**
- 默认离线模式
- 原有功能完全保留
- 配置文件兼容旧版本
- 可选启用在线功能

## 🐛 已知注意事项

### 1. 依赖库
确保系统包含：
- ✅ `libcurl` - HTTP 请求（MiMo API）
- ✅ `cJSON` - JSON 解析（已有）
- ✅ `stdlib.h` - malloc/free（已引入）

### 2. 唤醒词识别
- 当前基于 KWS 模型的 `VOICE_COMMAND_WAKE` 类别
- 阈值设置为 `score > 180`
- 如需更换唤醒词，需重新训练模型

### 3. MiMo API 调用
- 使用 `curl` 命令行工具（需确保系统有 curl）
- 简化的 JSON 解析（生产环境建议增强）
- 网络超时设置为 5 秒

### 4. 资源清理
- TTS 临时文件会自动清理（`unlink`）
- MiMo 服务在 shutdown 时释放
- 配置更新后需重启 `routine_mgr`
